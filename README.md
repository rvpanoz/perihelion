# Perihelion

A web-based 3D solar system VFX showcase driven by live NASA/JPL data, built on a small
TypeScript orbit engine.

## Commands

```bash
npm i              # install
npm run dev        # web + server in dev mode
npm run check      # typecheck + lint + test + build
npm test           # all unit/property tests
npm run fixtures   # regenerate Horizons fixtures (not implemented yet)
npm run snapshot   # refresh bundled data snapshot (not implemented yet)
```
